BitClock 比特时钟 - 像素风电脑使用时长追踪器
================================================

感谢使用 BitClock！


功能特性
--------

  追踪
  - 自动检测前台应用，记录每个应用的使用时长
  - 空闲检测（可配置 1-60 分钟无操作自动暂停）
  - 暂停/恢复追踪

  统计
  - 首页仪表盘：今日总时长、当前应用、应用排行、饼图、分类统计
  - 历史统计：按周/月查看，交互式柱状图
  - 7 天趋势迷你图
  - 每日使用目标设定与提醒

  界面
  - 像素风格 UI，三款像素字体
  - 暗色 / 亮色 / 自动三种主题
  - 自动模式：7:00-19:00 亮色，19:00-7:00 暗色
  - 自定义强调色
  - 中文 / English 双语界面

  提醒
  - 休息提醒（连续使用超过设定时间后提醒）
  - 每日目标提醒（接近时预警，达到时弹窗）
  - 退出时显示今日使用总结
  - Windows 原生通知

  系统集成
  - 系统托盘后台运行（悬停显示今日时长）
  - 开机自启动支持
  - 全局快捷键（Ctrl+Shift+S/P/T）
  - 窗口置顶

  数据管理
  - JSON / CSV 数据导出
  - 数据库备份与恢复
  - 自动清理旧记录（可配置保留天数）


使用说明
--------

1. 启动后，BitClock 会在系统托盘运行
2. 左键点击托盘图标打开主界面
3. 右键点击托盘图标显示菜单（打开/暂停/设置/退出）
4. 在设置中可以切换语言、主题和配置选项
5. 关闭窗口时会最小化到托盘（不退出）


键盘快捷键
----------

  应用内：
    1 / 2 / 3    切换页面（首页 / 历史 / 设置）
    Space        暂停 / 恢复追踪
    T            窗口置顶 / 取消置顶
    Esc          返回首页 / 关闭弹窗

  全局快捷键：
    Ctrl+Shift+S    显示 / 隐藏窗口
    Ctrl+Shift+P    暂停 / 恢复追踪
    Ctrl+Shift+T    窗口置顶 / 取消


数据存储
--------

  数据库：%LOCALAPPDATA%\BitClock\bitclock.db
  日志文件：%LOCALAPPDATA%\BitClock\bitclock.log
